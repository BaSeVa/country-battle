# Битва стран

Бои шаров-стран (countryballs) с рендером вертикальных роликов прямо в браузере: 1 × 1, команды, королевская битва, босс, футбол, турниры, лиги, шоу, «Захват поля» и чемпионат мира по футболу с отбором. 145 стран Европы, Азии, Америки, Африки и Океании.

**Сайт:** https://baseva.github.io/country-battle/

## Что делает репозиторий

| Что | Где | Когда |
| --- | --- | --- |
| Сайт на GitHub Pages | `.github/workflows/pages.yml` → ветка `gh-pages` | при каждом изменении `src/`, `data/`, `vendor/` |
| Проверенные данные стран | `tools/update-data.mjs` → `data/countries.json` | по понедельникам и вручную |
| Ролики дня | `.github/workflows/daily.yml` → **Releases** | каждый день около 08:40 по Москве и вручную |
| Голосование зрителей | Issues с меткой `battle` | бой из заявки с наибольшим числом 👍 выходит следующим |
| Сериал «Чемпионат мира» | `state/wc.json` | одна серия в день, после финала начинается новый чемпионат |
| История роликов | `state/history.jsonl` | строка на каждый ролик |
| Загрузка на YouTube | `tools/youtube-upload.mjs` | если заданы секреты `YT_*` |

### Данные из открытых API

`tools/update-data.mjs` собирает:

- **REST Countries** — площадь, координаты столицы;
- **World Bank** — население, ВВП, продолжительность жизни, доля лесов (последний год с данными);
- **Wikidata** — столица по-русски, высшая точка, ссылки на статьи;
- **Википедия** — короткая справка о стране (показывается под карточкой страны);
- **eloratings.net** — футбольный рейтинг Эло сборных для чемпионата мира.

Если источник недоступен, значения берутся из прошлой версии файла. При сборке данные встраиваются в страницу: «Битва цифр» получает категории ВВП, продолжительность жизни и леса, в чемпионате мира работают посев по Эло и корзины жеребьёвки.

Погода для арены берётся в браузере из **Open-Meteo** по координатам столицы (галочка «Погода» в разделе роликов): снег или мороз — зимняя арена, жара — пляж, ночь — ночная арена.

## Голосование

1. **Issues → New issue → «Предложить бой»**, впишите две страны.
2. Голосуйте за заявки реакцией 👍.
3. Ежедневный запуск берёт заявку с наибольшим числом голосов, рендерит бой, публикует релиз и закрывает заявку ссылкой на ролик.

## Запуск вручную

**Actions → «Ролики дня» → Run workflow.** Можно задать пару стран кодами (`ru`, `fr`), выключить серию чемпионата или загрузку на YouTube.

Локально:

```bash
npm install && npx playwright install chromium   # нужен и ffmpeg
python3 build.py dist                             # сайт в dist/
node tools/update-data.mjs                        # свежие данные
node tools/render.mjs duel --a ru --b fr          # бой 1 × 1 в out/
node tools/render.mjs wc                          # следующая серия чемпионата
```

## YouTube

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите **YouTube Data API v3**, настройте экран согласия OAuth (добавьте себя в тестовые пользователи) и создайте клиент OAuth типа **Desktop app**.
2. На своём компьютере: `YT_CLIENT_ID=… YT_CLIENT_SECRET=… node tools/youtube-auth.mjs`, откройте ссылку и разрешите доступ к каналу.
3. В репозитории **Settings → Secrets and variables → Actions** добавьте секреты `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`.
4. По умолчанию ролики загружаются **приватными**. Чтобы публиковать сразу, добавьте переменную `YT_PRIVACY` = `public` (или `unlisted`). Подпись канала в роликах — переменная `CHANNEL_HANDLE`.

Квота API по умолчанию — около 6 загрузок в сутки. Если клиент OAuth в статусе «Testing», refresh token живёт 7 дней: переведите приложение в «In production».

**TikTok:** прямой загрузки нет — берите ролик из релиза и планируйте через Metricool или TikTok Studio.

## Структура

```
src/        страница, движок, флаги, стили, факты
vendor/     mediabunny (кодировщик видео)
data/       countries.json из открытых API
tools/      сборка данных, рендер, голосование, YouTube
state/      состояние чемпионата и история роликов
build.py    сборка сайта в один index.html
```
